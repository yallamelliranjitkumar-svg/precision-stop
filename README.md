# Precision Stop

A fast timing-bar game for phones, tablets and laptops. A needle sweeps across a bar; tap to stop it inside the green zone.

- 3 chances per game, then it restarts automatically
- Chance 1: green zone is still. Chance 2: it moves at 0.25x the needle speed. Chance 3: 0.5x.
- Near miss (within 10 units of the zone) shows SO CLOSE! with the miss distance
- 3 near misses in a row earns a sticker token

Controls: tap the button or the bar, or press Space / Enter.

It is a single static `index.html` with no build step. Open it in a browser, or host it with GitHub Pages (Settings → Pages → Deploy from branch → main).
